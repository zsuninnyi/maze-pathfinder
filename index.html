    How to write it in an interview

    1. Say why this is BFS. Every legal step costs 1. A queue expands the floor in rings. The first time the finish comes off the front, that distance is the smallest one.
    2. Name three structures before you code. The queue holds cells you have reached and not yet expanded. The visited set stops a cell from being queued twice. The parent map remembers the step that found each cell, which is how you rebuild the route.
    3. Mark visited when you enqueue, not when you dequeue. The first time a cell is reached is the shortest way there. A later arrival is a longer walk to the same square.
    4. Rebuild from the finish. Follow parent back to the start, then reverse that list. The queue itself only tells you the distance.
    5. State the cost. Each open cell is queued once, so time and extra memory are both rows times columns.
